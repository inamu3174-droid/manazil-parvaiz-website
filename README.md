# Manazil Parvaiz — Author Website

Premium literary author portfolio for **Manazil Parvaiz**, featuring her collection of four books.

**Aesthetic:** Contemporary Literature × Editorial Magazine × Luxury Publishing × Cinematic Portfolio

## Books Featured

1. **Love in Modern Age** — Understanding Love and Loss in Today's Generation  
2. **The Mind We Don't Show** — Behind the Masks We Learn to Wear  
3. **The Miles of Silent Courage** — The Unheard Voices That Walk Miles Toward Tomorrow  
4. **Between Then and Now** — A collection of poems

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React
- React Router

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Import the GitHub repository at [vercel.com/new](https://vercel.com/new)
2. Framework preset: Vite
3. Deploy

Or connect the existing Vercel project linked to this repo.

## Configuration Notes

- **Buy / Sample links**: Edit `src/data/books.ts` and set real `amazonUrl` and `sampleUrl` values.
- **Contact email & socials**: Update placeholders in `src/components/Contact.tsx`.
- **Author quote**: Replace the placeholder in `src/components/Quote.tsx` with a real quote when available.
- **Author portrait**: Replace the placeholder block in `src/components/AuthorSection.tsx` with an actual image.
- **Journal posts**: Replace placeholders in `src/components/Journal.tsx` with real content later.
